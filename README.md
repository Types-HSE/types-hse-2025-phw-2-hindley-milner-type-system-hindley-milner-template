# Задание по системе Хиндли-Милнера

В этом домашнем задании нужно реализовать алгоритм вывода типов
для некоторых расширений системы типов Хиндли-Милнера,
**А ТАКЖЕ ТЕСТЫ**, проверяющие корректность решения.

## Формат сдачи

Решение принимается на любом языке; разрешается использовать готовые библиотеки.
При сдаче в GitHub Classroom для sanity check будет запускаться команда
`pytest`, запускающая все файлы `test_*.py` в репозитории как юнит-тесты.

## Оценивание

- [ ] **3 балла** за парсер входных данных;
- [ ] **4 балла** за вывод наиболее общего типа в базовой системе;
- [ ] **1 балл** за расширение системы встроенными типами `Int` и `Bool`;
- [ ] **1 балл** за расширение системы типами-произведениями и типами-суммами;
- [ ] **1 балл** за расширение системы рекурсивными определениями;
- [ ] **2 балла** за расширение системы взаимно рекурсивными определениями.

Баллы за каждую группу начисляются только при наличии тестов для этой группы.

Баллы вносятся в итоговую таблицу как есть,
без округления и без взятия `min(10, _)`.

## Описание входных и выходных данных

* На вход передаётся единственный модуль, написанный на некотором языке H--.
* В языке H-- есть всего 4 вида выражений: переменные, объявление анонимной
  функции, применение функции к аргументу, а также введение нового определения с
  помощью `let`. Вот пример, содержащий их все:
  ```haskell
  (\t u -> let v = u in t u v)
  ```
  Применение функции к аргументу левоассоциативно, а объявление
  анонимной функции с несколькими аргументами на самом деле просто сокращение
  для последовательных объявлений вложенных анонимных функций, т.е. пример выше
  эквивалентен
  ```haskell
  \t -> \u -> let v = u in (t u) v
  ```
* Если есть разночтения в том, куда ссылается переменная (т.к. параметры функций
  либо определения называются одинаково), то она ссылается на ближайшее из мест
  её объявления. В частности, следующее выражение
  ```haskell
  \x -> let x = x in x
  ```
  Эквивалентно вот такому:
  ```haskell
  \y -> let x = x in x
  ```
* Также в языке H-- есть _объявления верхнего уровня_, состоящие из имени,
  знака `=` и выражения:
  ```haskell
  id = \x -> x
  ```
* Модуль представляет собой последовательность объявлений верхнего уровня, где
  каждое следующее объявление может ссылаться на объявления выше по имени:
  ```haskell
  id = \x -> x
  const = \x y -> id x
  flip = \f x y -> f y x
  constt = flip const
  ```
* По соглашению пользователей языка H--, каждое объявление верхнего уровня
  занимает ровно одну строчку и имеет своё уникальное имя. Однако между
  объявлениями может быть произвольное количество пустых строчек; мы не будем
  тестировать поведение решения на программах с лишними пробелами,
  но решение должно обрабатывать такие программы корректно.
* Решение должно вывести наиболее общий тип каждого из определений верхнего
  уровня, разделяя имя и выведенный тип знаком `::`:
  ```haskell
  id :: forall a. a -> a
  const :: forall a b. a -> b -> a
  flip :: forall a b c. (a -> b -> c) -> b -> a -> c
  constt :: forall a b. a -> b -> b
  ```
  Если определение не типизируется, вместо типа для него нужно вывести `ERROR`:
  ```haskell
  omega = \x -> x x
  -----------------
  omega :: ERROR
  ```
  Напомним, оператор `->` правоассоциативен, т.е. тип `const` выше эквивалентен
  `a -> (b -> a)`. В выведенном типе не должно быть лишних скобок, а переменные,
  вводимые `forall`, должны быть как можно более короткими, но конкретный выбор
  переменных может быть произвольным.
* При расширении системы типами `Int` и `Bool` в систему также добавляются
  следующие встроенные определения верхнего уровня:
  ```haskell
  0, 1, 2, ... :: Int
  true, false :: Bool
  succ, pred :: Int -> Int
  isZero :: Int -> Bool
  ifThenElse :: forall a. Bool -> a -> a -> a
  ```
* При расширении системы алгебраическими типами данных в систему добавляются
  следующие встроенные определения верхнего уровня:
  ```haskell
  pair :: forall a b. a -> b -> a * b
  fst :: forall a b. a * b -> a
  snd :: forall a b. a * b -> b
  inl :: forall a b. a -> a + b
  inr :: forall a b. b -> a + b
  cases :: forall a b c. a + b -> (a -> c) -> (b -> c) -> c
  ```
* При расширении системы рекурсивными определениями грамматика языка и набор
  встроенных определений не меняются, но определения (как вводимые в `let`, так
  и верхнего уровня) могут ссылаться сами на себя.
* При расширении системы взаимно рекурсивными определениями в `let` можно
  вводить сразу несколько определений, ссылающихся друг на друга:
  ```haskell
  kek = \x -> let foo = bar; bar = foo in foo
  ```
  (здесь `kek :: forall a b. a -> b`).
  Определения верхнего уровня также могут ссылаться друг на друга:
  ```haskell
  isEven = \x -> ifThenElse (isZero x) true (isOdd (pred x))
  isOdd = \x -> ifThenElse (isZero x) false (isEven (pred x))
  ```
